## 当前路径与许可

锁定 `package.json` 与 lockfile 中的实际版本，本包采用自编的限定配方及明确参数合同。研究基线是 Shaders 4.0.2、源码 commit `9435282c29d3505c67eef427470c8d835095a199`；研究快照不证明本机安装或发布 tarball 已运行。配方以本包 `assets/recipes/` 与实际校验器为准，不声称支持任意JSON或全部上游组件。

开源实质部分保留 MIT 版权及许可，第三方依赖/字体按实际文件审查。官网 Content、免费/Pro预设、合集、sections 不作为本包可再分发模板库；具体业务使用需相应许可。[固定源码许可](https://github.com/shader-effects-inc/shaders/blob/9435282c29d3505c67eef427470c8d835095a199/LICENSE)、[官网 Content 许可](https://shaders.com/license)。本包不以付费账户、云预设或远程 MCP 为本地核心前置。

## 配方能回答什么

| 当前配方 | 适合的二维程序关系 |
| --- | --- |
| `luminous-order` | 平行光带层级、留隙、高光宽度和显露节奏 |
| `envelop-reveal` | 图形包裹、开口、遮挡与内外显露先后 |
| `affinity-field` | 节点聚合、连接距离、个体与中心的观看权重 |

适配器只接受已登记的单 root、无 children/resources 的生成器及其参数。`studyComposition` 是主体图、掩模、opacity 与 CSS blend 的同场合成，仅支持 `normal`、`screen`、`multiply`；它不提供真实反射、折射、三维空间或身体因果模拟。可见光场或掩模不能单独证明这些命题。

当前没有已实现并验证的项目自定义 Shader 注册、任意资源树或主题/布局配置入口；暖白比较板是当前实现，不是所有项目的美术目标。先由问题和足够样本决定路线，再分配 Shader 作用。能回答时复用现有能力；核心证据需要其他媒介时向主责提出相称的摄影、CG、排演或原型。只有具体研究需要缺失的实时耦合或承载表达、且在授权内，才开发必要扩展，实施前准确保留不支持。

## 有效运行

严格校验 recipeId、已支持参数、类型/范围/有限数、组件/属性、资源、ID及版本，冻结有效默认值。上游可能跳过未知组件、补默认值，GPU失败也可能 resolve 后 no-op；包内不得继承这些行为作为成功。记录真实 device、有效绘制/读回、尺寸、失败回调/device loss及输出，无法核实时保持未验证。

预览与采集使用同一已验证渲染策略。接口未公开的 colorSpace/toneMapping 不伪传，内部线性/P3不证明ICC、sRGB、HDR、ACES或透明视频正确。文字、中文、构图、透明与边缘要看最终画面。源资产保护依 [素材合同](asset-operations.md) 判断实际转换链。

当前权威采集另由固定SDR sRGB profile约束，实际读取WebGPU canvas配置的colorSpace/toneMapping、视口、DPR和偏好；声明与观测冲突直接拒绝。这只证明当前浏览器输出配置与读回，不构成显示器/印刷ICC或跨GPU像素一致承诺。研究图层与时间的观看关系时，可按授权使用studyComposition；需要真实物理的命题另取充分媒体，不能把混合称为材质验证。纯GPU读回与浏览器主体合成分别取证，静态比较采用同版主体合成。

每完整方向的真实研究必须与决策假设相关，写明支持对象或承载品质的证据；需要时看启用/关闭对照。无GPU/渲染失败时可浏览同版静态资料并显示原因，但不能成为无Shader完整模式。缺输出、空画布、失效资源、版本错配保留失败，不以占位兜底通过。

## 交互与快照

本地板面先展示同版真实 poster，默认只当前方向主动播放，切换销毁/暂停旧实例。确需并排动态时先实际测性能，不能以单画布规则限制必要表达。减少动态是观看模式，不删除实际制作证据。

调参、暂停选帧和时间暂存，保存由服务按参数合同提交；导出/审阅绑定 [项目快照](project-contract.md)。支持范围仅限可重建自编程序研究；不能宣称全库任意seek/seed/倒放或跨GPU像素一致。状态模拟、随机热启动、视频解码按实际能力分别处理。不可重建就拒绝同状态导出或保持未验证，不改成默认参数。

## 导出与运行环境

本地 bundle、合法授权资源及锁定依赖走同源回环服务。只绑定 localhost/127.0.0.1，处理端口冲突、资源错误及关闭；不得把 file: 双击、CDN缓存命中或第三方iframe当可靠本地运行。宣称离线前需断网冷启动。

HTML是主交付；PNG同版总览默认输出；PDF首版能力需实际导出验证，项目按需生成。MP4/WebM仅当前实现已实测且任务需要时支持，未实现准确拒绝。离线视频应由浏览器顺序推进/读回再编码，不把ffprobe参数当动态验收；最终原速完整观看。4K/HDR/透明视频或DCC接入另按实际需求验证，不默认宣传。

先实际运行依赖/能力探测及包内测试，查看真实浏览器console、GPU、布局与运动。记录实测设备/浏览器/构建/帧时及限制；缺证据与失败不能默认通过。机械命令返回0只证明该命令声明的技术范围，不证明审美、独立审阅或用户接受。
