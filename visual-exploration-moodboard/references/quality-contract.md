# 品质与审阅合同

用于建立制作前依据、自检、独立首评和修订复核。目标保留相关 Awwwards、Webby Awards、FWA 优秀作品的竞争力；不承诺获奖，不把情绪板范围扩成最终影片/品牌/实体工程。

## 前置比较与两个结论

方向制作前，分别保存对象与承载体验的成功条件、关键失败、相关作品、比较理由与关键差距。对象采用相应媒介标杆；承载从相关优秀网页选择。整个可复用标杆集合覆盖三套奖项，单项目无需凑齐三种。核对作品、奖项、年份/类别和原作来源；不同奖项按自身官方标准理解，不制造通用官方权重表。

实际打开所需页面/媒体，记录设备、视口、访问条件、看过的画面/片段/交互和未知项。截图、摘要、列表页、HTTP 成功均不能证明动态或交互；受限时记录范围并选相关可观察替代。当前官方入口：[Awwwards](https://www.awwwards.com/)、[Webby 评判标准](https://www.webbyawards.com/judging-criteria/)、[FWA](https://thefwa.com/)。引用前核实当前页面，不将旧研究快照视作现场观察。

首轮制作与审阅引用准确基线及实际运行关系。新证据改变比较对象时保留原基线、原因、维度和受影响结论；不因访问失效或结案需要静默降低标准。文件修改时间和 baseline_ready 不能证明前置或实看。

分别判断研究对象和承载体验，不能平均互偿。每类记录成立、未达标或证据不足及具体观察。网页精彩而材质/身份错误时对象失败；对象强而网页妨碍比较或只有普通模板水准时承载失败。简单可用和复杂动效均不自动达到目标。网页本身也为研究对象时可共用证据，注明各自使用状态与问题。

## 实际观察维度

以下是本包的工作维度，不冒称奖项官方分数表。按项目分别落到两类品质。

| 维度 | 判断依据 |
| --- | --- |
| 创意与原创 | 明确命题及可观察假设，方向/变体有实际差别，参考转译成立而非换皮肤 |
| 艺术指导 | 构图、空间、光色、材质、字体和信息形成观看路径，主体身份与真实比例成立 |
| Shaders 与动态 | 机制服务决策，有可见作用；有效过程、速度、停顿/循环/交互成立，无闪烁/接缝/卡顿关键缺陷 |
| 排版与内容 | 真实标题/中文/图文关系可读，字体、裁切及移动呈现合理 |
| 体验与使用 | 比较、细看、选择与必要操作直接帮助判断，键盘/触控/减少动态模式可用 |
| 技术完成度 | 当前快照实际载入/绘制，资源释放、导出、重开与已声明环境真实成立 |
| 来源与接续 | 来源/代理研究/采用范围可追踪，下游三类交接可用，概念未冒充事实或真人批准 |

可用“明显不足、可用但普通、专业成熟、有竞争力依据”辅助描述，数字只作辅助。任一关键失败不能被均分、迭代次数或代理人数覆盖。分别回答相对前置标杆哪里有竞争力、哪里落后、证据在哪；只有专业成熟或无重大错误仍不足以声明目标达成。

## 观察与修订

查看最终桌面宽屏、中等桌面窗口、移动竖屏实际布局，记尺寸/DPR、浏览器/GPU及构建。操作导航、比较、调参、保存/导出、键盘、触控、减少动态；动态看有效过程、接缝和输入/退出恢复。最终 PNG 实看，项目要求 PDF 则逐页实看；视频仅当前能力已实测时生成，解码参数不能替代原速完整播放。

性能先定目标设备预算，实测加载、帧时、内存/切换恢复。动态初始目标稳定30fps以上，60fps及4K不得未经测量保证。优化资源/活动实例，不通过删除必选机制隐蔽降级。静帧、测试通过、文件非空各只证明对应事实。

自检后才派独立审阅。未参与制作者先读原需求、最新纠正、锁定、两类成功条件、前置标杆/变更记录、当前作品及必要运行信息，收回“先首评后对照”确认；首评封存前不给自评/评分/完成结论。已参与制作或接触解释须披露，不能冒称独立首评。

重大命题、主布局/观看路径、主导动态或核心交互改变需新的独立首评；小修只复核受影响范围并绑定新版，缺新证据的部分保持 pending，不能沿用旧整板通过。统一调色/裁切/后处理改变对象关系时，对象也须重查。

修订记录问题/证据、判断、实际改动、受影响版本和复查。先修阻断判断、破坏锁定及最影响整体观看的问题，不改评判口径宣布进步。技术、对象、承载、独立审阅、交付和用户接受分别报告；预算到达不自动通过。用户接受独立于代理就绪。

## 标杆入口

这是可复用检索入口，不是已经完成的新项目观察，也不要求每个项目机械凑齐三个奖项。按本项目媒介、机制和观看条件选相关作品，制作前实际查看原作并冻结比较维度；官方获奖页与原站体验分别核实。

- [Awwwards：Igloo Inc](https://www.awwwards.com/sites/igloo-inc)；[作品原站](https://www.igloo.inc/)。
- [FWA：Igloo Inc](https://thefwa.com/cases/igloo-inc)；可与同一作品跨奖项比较，不能把一个作品算成三个独立标杆。
- [Webby：Igloo Inc / Best Visual Design – Aesthetic](https://winners.webbyawards.com/2026/websites-and-mobile-sites/features-design/best-visual-design-aesthetic/361001/igloo-inc)。Winner、Nominee和具体类别严格分开。

静物/影像/空间的对象研究另选其专业标杆。网页奖项不自动证明玻璃、金属、人物或空间关系成立；网页可访问或官方缩图也不代表看过原站动态。访问失败留下准确不足，实际补看若在制作后必须如实记为补充，不能背填前置观察。
