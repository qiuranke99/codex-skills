# Check the evidence that supports the claim

One reference is an exact image or video work/cut, not a channel, portfolio
homepage, search result, or unlabeled collection.

## Media and provenance

- An opened page or HTTP 200 proves neither image content nor video playback.
  Check for redirects, deleted/private notices, challenges, empty players, and
  unloaded placeholders.
- For images, inspect the actual selected image at a size sufficient for the
  feature being discussed. If a page has several images, give a locator such
  as the caption or position so the user can find the same one.
- For video, observe the relevant segment in motion before making camera,
  blocking, edit, timing, or sound claims. A poster or transcript does not prove
  them. Record useful time ranges and playback limitations. For claims about
  the entire edit, inspect the entire relevant work.
- Prefer the creator, brand, production company, agency, or official
  distributor. An accountable craft archive with matching work and credits can
  support provenance. Recover origins behind reposts when possible.
- Distinguish observed media from page-reported facts and inference. If media
  cannot be inspected, label it as a lead and omit unsupported visual claims.
  Do not count such leads as verified references.

## Selection

Deduplicate the actual work, including CDN variants, reposts, alternate crops,
regional cuts, and same-campaign repetitions. Keep versions when comparing them
is part of the task. Perceptual hashes are optional tools for a large dataset,
not mandatory proof for a small board.

Check the hard brief first, then compare useful mechanisms and execution.
Avoid source, creator, region, or visual repetition that adds no decision value.
A narrow study may appropriately use one creator or domain. Do not require
arbitrary diversity counts, scores, or rejected-item quotas.

## Access and use

Use public sources where they suffice. Use authenticated sources only within
the user's authorized context. Do not expose unrelated account state, cookies,
tokens, private messages, or browser information. Do not post, like, follow,
message, purchase, or change an account as part of reference research.

Distinguish viewing a work, sharing its link, downloading it, embedding it in a
board, and reusing it commercially. A visible image is not a rights grant.
Download or embed media only when the requested deliverable and source rights
support it; otherwise use an attributable link. A session-bound observation
does not establish that another person can open the link without that session.
Label that limit or supply a verified public fallback.

## Honest delivery

Retain links, observation times when material, and useful tool evidence. Make
only the claims that those observations support. A checklist or file hash can
organize evidence; it cannot prove that an unperformed browser action happened.
External signatures and cryptographic attestations are not prerequisites for
ordinary reference research. Report actual checks and unknowns directly.
