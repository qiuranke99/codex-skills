# Search methods

Choose methods that change the evidence being retrieved. Several adjective
variants over the same source are one method. Use only as many as the brief
needs; do not force a broad campaign search onto a specific lookup.

| Method | Use and query shape | Main weakness |
| --- | --- | --- |
| Category and context | Product/service + campaign or format + scene/use + market/year | Generic product stills and SEO results |
| Visible mechanism | Full-body staging, monumental set, translucent material, negative space, hard-edge light; camera orbit, gesture match, macro-to-wide reveal | Technique labels may not match the actual media |
| Credit graph | Work → director/photographer/DOP/set designer/stylist → studio/agency/brand → adjacent work | Credits must come from evidence, not resemblance |
| Craft archives | Awards, trade publications, production-company rosters, original campaign pages | Prestige and editorial selection are not effectiveness evidence |
| Adjacent disciplines | Fashion or installation for scale; architecture/theatre for space; title design/VFX for motion; dance for blocking | Explain how the mechanism transfers to the brief |
| Challenger | Preserve hard constraints while testing a materially different direction | Difference alone does not make it useful |

For global briefs, include relevant local-language and regional sources when
English search narrows the result set. For current-market questions, inspect
current cuts and placements in ad libraries. Neither is a mandatory quota.

When results are weak, identify the missing axis before searching again:
subject, scene scale, human presence, visual mechanism, temporal mechanism,
source population, or access. Follow a strong work's credits instead of endlessly
rewriting adjectives. Expand only uncovered directions and replace failed items
through another source or method.

Record useful queries, failure reasons, and source links in working notes when
they help resume or explain the work. No preregistration, agent identity graph,
fixed raw-candidate count, or separate failure ledger is required.
