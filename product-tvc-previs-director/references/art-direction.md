# 产品依据、美术与布局图

在分析素材、设计元素、调用图像生成和核对共享置景时读取。本文件给出创作判断方法；候选元素和数量不代表配方事实、统一美术标准或图像模型保证。

## 1. 按属性分配输入权威

实际打开全部图像，先查可见事实，再做设计推论。原图、缩略图和OCR是不同证据；OCR识别结果须与清晰图像对照。多图存在分歧时定位到具体属性，不平均混合。

| 输入 | 负责 | 不自动负责 |
| --- | --- | --- |
| 产品白底图 | SKU、比例、可见部件、材料、固有色、透明度、标签布局及可读文字 | 未见背面/内构、成分、功效、出镜实例数量 |
| 主/辅影调图 | 已指定的色系、亮度、明暗分配、光质、材料受光气氛 | 其他产品、品牌、场景、人物或具体机位 |
| 美术方向资料 | 被指定的材料语言、形态组织、层次和动作启发 | 逐张复刻、一图一镜、首尾帧 |
| 明确场景参考 | 已锁定装置、主要结构、比例和相对位置 | 不存在的装置功能、产品事实、镜数 |
| 本流程生成的布局图 | 产品占位、置景构型、负空间、前后层、可见遮挡及其布局机位 | 最终产品外观、真实三维精度、整片恒定机位 |
| 后台白模预演 | 已实现的相机/主体路径、朝向、画面关系、速度和时间 | 真实材质、包装文字精度、最终视频质量 |

对SKU、物理状态和实例分别记录。同SKU开盖图只是另一状态；多角度图不是多个实例。产品图与布局图有冲突时修正占位或摄影，不给产品换形状。明确关键帧只锁用户指定属性和时刻，不能擅自扩大成全程姿态锁定。

每份输入保留素材ID、相对业务路径/可定位文件、SHA256、尺寸、来源、用途与适用布局/镜头。写作时看过的资料不必全部上传给视频模型；上传集合在后续按入口真实能力决定。

## 2. 从当前产品导出置景

先提取少量真正有识别度的线索：外轮廓和比例、开合或接缝、曲面/切面关系、颜色的分布、透明/粗糙/金属等可见材料、已知内容物形态、用户给定的品牌意图。把“图上可见”“用户提供”“导演推论”“未知”分开。

内部提出少量有区别的方案，通常比较2—3条已足够；按产品关联、可见事件、镜头覆盖、结构可实现性和制作成本选一条。无需把选焦段或选元素逐项退给用户。只有方案改变已锁定创意或存在不可消解事实冲突时才提出具体选项。

为每个主要置景元素写一条因果：

> 产品依据 → 采用的形态/材料隐喻 → 空间角色 → 镜头内动作或观察变化 → 不承担的产品事实。

例如，棱面包装可启发错层平面与折面光影，圆弧轮廓可启发弧形通道与间距节奏；这些是设计选择，不证明内容物成分。透明层可以服务前后叠合和透射观察，但不必成为水滴；彩色包装可以用色面、粗细尺度或运动次序组织，也不必套花瓣。不得把产品名称中的植物词直接写成未经确认的有效成分或功效。

元素必须在至少一个镜头中做事：形成前景掠过、打开遮挡、承托比例、投影移动、材料形变、揭示产品或为切点建立关系。只有装饰、换任何商品都成立且抢走品牌注意力的元素应减少或重设计。空场景和复杂置景都可以选择；保留用户指定的场景结构，不能为省建模而删成无缝背景。

## 3. 共享布局与空间设计

按空间状态划分布局，按信息目的划分镜头。15秒广告通常可从2—4套主布局规划，但一套足够或需要更多时按实际理由决定。特写常复用同一空间，新增真实可见的局部代理即可；只有关键构型、遮挡、产品排列或展示时刻改变到不能共享时才新增布局。

每套布局同时维护两种产物：

1. **AI布局图**：一张能读懂前中后关系、产品占位、主装置与负空间的中性图；复杂遮挡确需额外视角时再补，不机械生四视图。
2. **空间设计记录**：布局ID/版本、设计用途、对象ID与可复用基本形、尺寸比例、位置/旋转、前中后层、关键遮挡、接触/开放通道、布局相机及目标画面关系。

坐标、单位、对象字段和时间编码以[运行契约](runtime-contract.md)为准。用产品代理高度作为相对尺度参照时，须在契约中明确它对应的实际场景尺寸；不把估算尺寸写成测量结果。前中后层既要有空间距离，也要有从布局机位看得到的画面关系。

每个布局注明多个镜头如何使用：全景建立、角度揭示、贴面特写、穿过开放间隙、落版等。预先验证额外机位会否暴露图上不存在的背面或不成立的支撑。单视图无法确定的背面结构可保持简单，并标为设计补足；不可据单图承诺精准三维还原。

产品占位默认基本体，置景则按设计需要使用基本体或本包支持的低模mesh。弧形屏风、折面、开口通道可用少量顶点和面表达其关键空间关系；复杂度放在影响构图、遮挡和运动的部分。不因代理产品很简化，就把场景一律压成四种基本体，也不能生成布局后为适配脚本删除主装置。顶点/面与尺寸缩放规则见运行契约。

## 4. 生成布局图的实际任务

优先使用可用的原生图像工具。准确记录实际工具和返回文件，不冒称未暴露的型号。为编辑输入先实际查看；按当次授权传递最小必要素材。需要产品图作分析并不自动允许上传它给任何外部服务。

图像任务包含以下内容，写成自然语言即可：

- 当前产品的可见设计依据和选择的核心视觉事件。
- 产品使用哪个基本体占位、实例数、相对尺寸、朝向和位置；不生成Logo或包装文字。
- 置景对象、前中后层、重叠顺序、接触点、开放通道和留白位置。
- 布局机位、画幅、视线目标、产品占比与关键形状的可见程度。
- 中性白模材料、能区分体量的照明与足够可读的阴影；不将最终风格图的彩色外观复制为布局权威。
- 必须保留的构图关系和允许由生成工具补充的细节。

生成后实际打开图，核查产品占位是否被改成细模、实例是否增殖、遮挡/通道是否成立、关键装置是否保留。可修复时在现有授权内迭代；已锁定的有效关系写入修订请求，不能整套换掉。保留实际输入说明、输出文件与哈希，更新空间设计记录，使两者说的是同一版本。

文本方案不能冒充图像。合成fixture是开发程序按明确几何画出的测试示意，须保留fixture类型与来源，不能转写成AI生成记录。图像工具不可用或授权止于准备时，保存设计和待生成项，布局阶段仍未完成。

## 5. 布局图与Blender校正

先以`prepare --mode layout`派发本包脚本，只在布局机位渲染低分辨率静帧，再实际并看AI图与渲染。此阶段不建整片动画、不渲逐镜视频。比较产品中心/占比、主要元素边界、层次、重叠次序、通道宽度与负空间；关注对镜头功能有影响的差异，不做无依据的逐像素追图。

优先通过已声明参数修正尺寸、位置、相机、目标或焦段。若图中透视、接触或遮挡关系无法共同成立，确定保留哪些核心关系，再在授权内修图或调整空间；记录该差异，不能悄悄宣布重建精准。每次影响结构或构图的修改都重渲受影响视角。

布局对照完成后，代理记录每套布局的源图/预览图哈希、具体观察与结果，再用`prepare --mode build --layout-review`进入新动画lane，字段见运行契约。这个技术/视觉自检步骤无需例行要求用户再批准；用户原先指定的审阅节点照常保留。对照记录只覆盖其实际版本，不能沿用到已修改契约。

产品代理只承诺可见占位和运动。若动作需要盖与身分开、真实轮廓或特定接触点，则增加最低必要部件；尚未建的文字、倒角、透明内部和精细形变均应在差异说明中出现。不要把“简单几何替代产品”误用为“简单几何替代全部美术设计”。
