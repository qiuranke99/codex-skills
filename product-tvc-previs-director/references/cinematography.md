# 摄影、动态与剪辑设计

用于镜头规划和实际预演修正。参数是当前画面目标，不是设备规格、统一行业阈值或视频模型精度承诺。执行字段与插值规则见[运行契约](runtime-contract.md)。

## 1. 信息与时间先于镜头数量

用一句话写清观众先认识什么、随后发现什么、哪次变化改变预期、最后记住什么。围绕核心事件分配建立、发展、转折、高潮与收束，它们不必各占一镜。默认15秒、9—12镜，用户锁定的规格优先；镜数不得由附件数量决定。

先留片尾1—1.5秒稳定阅读，再给身份辨认和关键因果足够时间，剩余时间分配进入、动势与切换。镜头不均分，少量快镜可以作为标点，有过程的镜头需要发展时间；删除重复标签/瓶肩特写，不能用增加切点掩盖动作没做完。全片唯一时间线包含转场、变速与停留，生成余量另列。

每镜写“注意对象 → 因果动作 → 退出状态”。相机、主体/料体/置景和光影有各自起态、路径、速度与终态，围绕主信息同步或错峰。相邻镜不必都从静止开始、镜尾不例行刹停；大幅运动不等于全程高速。

## 2. 从画面目的选择焦段与机位

按此顺序做选择：

1. **主信息与景别**：建立整体关系、显出结构比例、观察表面、揭示部件或进入料体细节。
2. **视角与构图**：需要看见哪面，标签/接触点在哪，哪些部分允许裁切，前后层如何重叠。
3. **传感器与焦段**：在声明的传感器和画幅下选观察方式，再配合距离与朝向实现目标。
4. **空间与安全范围**：从起点到终点检查占比、裁切、遮挡、相机与对象间隙、品牌可见性。
5. **渲染校正**：用实际投影和预览修正，不能只凭焦段名称或固定距离通过。

24—35mm可作为强调近远关系的候选，50—85mm可作为形态与中近景候选，90—120mm可作为局部观察候选；这些范围可交叉使用，不能固化为“全景必35、特写必100”。选择同一焦段也可以通过不同机位表达不同信息。白模相机设置的焦段不证明真实镜头最近对焦距离、微距放大率或景深。

透视由视点及相对空间决定；更改焦段后为保住占比而移动相机，会同时改变看到的关系。因此，主体高度约占画高多少、标签是否进入安全区、前景边缘何时掠过，比“85mm高级镜头”更有执行价值。数字只保留对制作与核对有用的部分。

镜头可以经过大幅尺度变化后回到接近开场尺度。不能仅比首尾图就判定有无景别发展，应检查镜内关键时刻。纯横移、拉焦、画面滚转或数字缩放不单独算纵深机位发展；近距广角不能以产品比例失真换取动感。

## 3. 路径、目标朝向和速度分开设计

位置路径写从产品哪侧、何高度/距离出发，沿什么开放空间到哪里；目标朝向写看向标签、肩部、装置或料体哪处，何时移交。绕物方向注明从上方俯看顺/逆时针，画面滚转另列。目标相对主体运动时须明确是跟随对象还是固定世界位置。

| 信息目的 | 可用组合 | 必须看到的结果与检查 |
| --- | --- | --- |
| 从整体进入结构 | 收紧弧线前推＋升降＋目标移交 | 整体变局部，侧面与正面依次展开；不穿包装、不强迫标签脱离瓶身朝前 |
| 展开置景层次 | 斜向横移＋纵深接近＋有限反向摇摄 | 前景掠过、遮挡打开、产品占比变化；相机不能把全部变化跟随抵消 |
| 高位关系转向体量 | 下降弧线＋环绕＋俯仰 | 顶面关系转成侧面体量，前后遮挡合理；机位降低后不能仍保留不可能的顶面量 |
| 进入微观再回产品 | 开放间隙穿行＋贴面推进＋转向/回望 | 近层与远层接力；明确间隙真实存在，不把“探针”写成穿瓶壁 |
| 高潮后建立落版 | 外扩后拉＋上升/小弧绕＋主体归位 | 局部展开为完整产品和场景，运动先完成，再进入稳定阅读 |
| 强调运动形态 | 相机弧绕＋主体独立平移/倾转 | 相对角度和画面占比确实变化，阅读窗口降低相对速度，文字始终贴附表面 |

从主事件选择路径，不要求每镜换一次器材名。速度可积蓄、突进、持续推进、错峰或减速，不机械套统一“缓入缓出”。关键段的时间、位置/朝向节点和插值按契约落地；需要带速度切出时不能在末端无意归零。脚本应提供稳健朝向和可读回曲线，但实际播放仍需判断转向是否自然。

本包Hermite路径的相机/对象`endpoint_mode`默认`continue`，端点按单边割线斜率保留动势；只有明确停车才设`stop`令端点导数为零。内点C1连续和相邻重复字段形成的停留不变，不把全部镜头自动刹停。

防抵消要同时看三个参照：主体相对世界、相机相对主体、画面内位置/占比/遮挡。相机复制主体速度造成近似静止时，调整滞后、超越、弧线、深度或主体方向。用户锁定产品全程竖直时保留锁定，以平移、纵深、独立置景/料体动作完成动态，不偷偷解除姿态。

## 4. 光影是画面事件

逐镜用“来源或反射/遮挡条件 → 作用表面 → 起始亮暗形状 → 路径和范围 → 时间变化 → 新信息/结束形状”设计。高级变化来自形状、层次、节奏和材质信息，不来自术语数量。曝光、白平衡和产品固有色保持稳定。

例如：宽反射从侧缘进入曲面，在瓶肩处由长条压缩为弧面，再离开文字阅读区；遮挡边缘沿装置折面移动，先揭出边缘再揭出深度；料体厚薄变化让固定背光形成薄缘亮、厚部保留密度。根据实际材料选反射、柔半影、负补光、透射与背光，不把粗糙平面当镜面、不把所有产品变玻璃。

| 用户条件 | 可以发生的变化 | 不应扩张或偷换 |
| --- | --- | --- |
| 气氛稳定 | 局部光影与位置可以改变，整体色系、亮暗气质连续 | 不自行变成背景像素固定 |
| 背景照明固定 | 主体独立受光或视点/主体运动；背景可有合法透视 | 不让主体动态光溢出改亮背景 |
| 背景画面固定 | 产品/料体表面响应，控制背景投影与视差 | 不靠换背景或移动光斑做动态 |
| 全部灯具与遮光条件固定 | 主体、表面法线/厚度及观察角变化产生响应 | 不暗加扫灯、移动反射板或无源阴影 |

白模只验证当前实际实现的照明层面。最终色彩、精细反射、折射、料体散射若未在预演模拟，记录为外观设计，不说预演已证明它们。设计照样要具体，不能因技术代理简单就把光影正文削成“高级扫光”。

## 5. 物性与动作因果

需要料体时先记录“有限初始物量/状态 → 受力或操作 → 可见变化 → 结束物量/状态”。把可见产品事实、用户提供的作用事实和外部导演意象分开。产品名称不证明黏度、配方、拉丝、反应或功效。

- 流动阻力、表面张力和惯性分别判断；厚部滞后、薄缘伸展或回缩应与材料证据一致。
- 释放需要真实开口/动作依据，瓶内减少与外部增加关系相容；不能封盖渗料、切镜重新喷同一份。
- 混合需要初始界面和可见发展，不能一切即均匀、下一镜又回原始分层。
- 外部凝胶、色面或颗粒可以表达触感与形态，但不冒充内部结构、成分或疗效。
- 广告时间压缩可省等待，仍保留关键因果；程序化代理形变不能宣称已完成流体物理仿真。

需要真实接触和部件互动时补最低必要几何，或者在创意允许范围内改变摄影回避未知结构。禁止通过模糊、遮挡或“抽象CG”掩盖违背产品事实的动作。

## 6. 先选镜间关系，再定切法

每个切点写“前镜切出状态 → 连接关系与时刻 → 后镜接入状态”。关系先分为同一事件续接、视觉联想或不同展示时刻，再选择动作中切镜、图形/方向/光色匹配、实体遮挡、甩镜、尺度反差、有意硬切或时间省略。

匹配时只约束需要连续的条件：动作续接要接进度；图形联想要明确位置、尺度和方向；相机反向可以是有意动势反差，不能笼统称全部速度连续。透明介质不是黑幕，不得临时变不透明藏切点。任何路径不得穿过实心包装来实现转场。

已混合、释放、消耗或拆封后回完整售卖状态，应明确通过剪辑切到同SKU的独立展示时刻；不写倒吸、补满或自动复原。一镜到底不能暗藏这种时间切换。

片尾从相机构图、产品主姿态和品牌信息全部落位后开始计时，默认稳定1—1.5秒。继续推拉、入场、转场和淡出不计入；轻微余动只能在不妨碍阅读时保留。文字首次出现很晚时需增加可用阅读时间。

修改后沿产品状态、动作阶段、相机、光影和切点检查前后依赖，直到重新接回未变部分。重渲实际受影响镜头并重合成，保留锁定内容；不能只改提示词而让媒体仍是旧版本。
