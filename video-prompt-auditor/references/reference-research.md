# 参考研究与证据

这是用户在当前任务明确要求时才启用的附加研究；默认提示词校对不读取或执行本流程。按当次需求重新选片，不能沿用固定影片充当所有项目的答案。每条参考应回答至少一个具体审查问题，结果可以支持保留、修正、收窄风险、不可迁移或仍未知；不要求每条片都制造新改动。与作品相似的颜色或题材不足以证明其镜头机制可用。

## 先核实观察通道

从文本先定位会影响裁决的具体疑问，例如“短镜怎样既展开尺度又看清动作”“产品揭示怎样与音乐停顿衔接”。按当前用户的研究范围确定必要维度；只研究运镜时，听音可不适用，不能因此阻塞已经完成的视觉研究。综合视听研究则须覆盖所需的画面与声音维度。

在大量检索前，用一个合适片段实际试通当前入口：核实本次问题所需的时序画面、时间位置；涉及音乐或声画关系时还须实际听辨声音。记录本次入口和实际收到的观察类型即可，不另建能力评分表。工具说明、视频链接、播放进度、声卡出声、音频文件生成或被附加成功，都不能单独证明代理已获得相应观察。

成功后沿同一路径扩展至本轮目标作品数；只获得单帧或稀疏采样帧时，按帧证据范围分析，不记为正常速度连续看片。只获得字幕或音频数值特征时不记为听音。能力不明先做小范围实测，不凭旧记录断言当前平台永久可用或不可用。

入口受阻时按原因尝试合理的不同路径：原发布与合法替代来源解决访问问题；当前可用的其他视听入口解决观察类型缺失。相同接口反复换视频不会新增音频或视频观察能力。没有合规可用路径时交付已完成的提示词校对，列出附加研究缺失的观察类型及继续所需条件；仅研究保持未完成，不降低作品目标或把抽帧改名为完整观看。

## 选取和检索

1. 从原需求提取主体/题材、表达目标、片长、横竖版、情绪与节奏、主要制作限制。缺少但不妨碍审查的信息用明确假设处理。
2. 用户要求多片研究却未指定数量时，选择 3–5 条不同作品，尽量至少两条直接相近；确实缺少时说明差异与研究缺口。指定数量或只对照某一作品时按其范围，不自动扩成多片。给入选作品一句用途，避免不同作品只重复同一机制。可补一条相邻领域参考，解释它仅支持哪些摄影/剪辑/声音判断；不规定跨品牌、跨国家等数量配额。
3. 从品牌、导演、摄影师、制作公司、代理商及原发布频道寻找可追溯的实际作品。搜索引擎负责发现，具体视频页负责定位。不要只按“高级、大片、电影感”堆搜索词。
4. 使用已实测的观察路径访问公开网页播放器、可合法访问的媒体或已有授权的本地视频；浏览器或桌面控制遵守该工具自身的使用说明。搜索摘要和页面文案只帮助定位，不能当看片结论。
5. 记录不可访问/无音轨/错版本等原因，改查原作者发布或另一条相近作品。合理替代都无法核实时交付文本校对并单列研究缺口，不无限重试同一失败入口，也不把目标数量降成已完成数量。

用户提供且本轮已实际核实的参考可以计入。要求多片而仅有一条可看的参考时，研究仍未完成；仅要求对照一条时则不凭空加数量要求。不得为补数量复制同一作品的转载或不同清晰度版本。

## 观看记录

每条最少保留以下信息，可直接放在报告表格中，不必创建额外台账：

| 信息 | 要求 |
| --- | --- |
| 作品与版本 | 标题、作者/品牌、具体剪辑版本或时长、稳定来源链接 |
| 匹配关系 | 与当前需求的相似点、差异、哪些判断可迁移 |
| 实际范围 | 整片或明确起止时间；正常速度连续播放范围；实际听音范围 |
| 证据定位 | 当前工具观察/媒体路径/已有审阅记录；关键分析标作品时间码 |
| 未验证 | 未看部分、听不到音乐、帧率未知、访问依赖等 |

先正常速度连续观看理解节奏，再回看关键片段定位动作、切点与转场。播放进度前进只证明播放器动过；截图只证明那一刻的画面；它们都不能单独支持“完整原速看过并听过”。只有实际获得相应视听观察才填写已看/已听。

无法精确逐帧定位时使用约数时间码。没有直接依据不能给出精确 BPM、调性、乐器品牌、镜头焦距、轨道距离或摄影设备。可写“听感为规则四拍、低频脉冲逐段加密”等有实际听辨支持的描述；推断另外标注。

## 每条参考的拆解

以下为可选分析维度；按本轮问题选择，不把未要求且不相关的维度变成完成门槛。

- 结构：开场抓取、信息展开、变化/高潮、结尾分别怎样建立；只看片段时只分析该片段。
- 镜头比例：明确分母与统计区间。可按镜数、时长分别比较景别与主体/细节/环境等功能类别，不能混用。
- 镜长和节奏：主要镜长范围、长短交替、加速/停顿/呼吸位置；不要把平均镜长当全部节奏。
- 镜内变化：选择可定位的代表镜，记起止景别、尺度跨度、路径、速度发展、前中后景关系与揭示的信息。
- 剪切与转场：切点发生在动作什么阶段，连接的是运动、形状、方向、视线、声音还是意义；两侧条件是什么。
- 音乐：音色/拍感、密度与段落发展、进入退出、重音与画面关系。听不到即保留未验证，不能从画面、字幕或自动转写猜音乐。
- 对当前稿子的启发：具体对应镜号，说明“当前疑问 → 实际观察及时间码 → 裁决 → 当前修法与成立条件”。观察到的成片效果不自动证明原制作技术、相机参数或当前生成模型能复现；核对本稿的时长、空间、锁定、参考职责与声音条件。不同作品彼此的差异也应参与判断，不能用单片风格定全片规则。

达到本轮作品数量且必要问题和研究维度已有足够观察后停止扩搜；证据不足则保留对应缺口。研究深度随不确定性分配，不以固定分钟数或填表数量代替判断。

## 复用与权限

借鉴镜头和视听组织机制，保留用户的创意、身份、内容与时长。研究本身不授权下载、上传、剪入参考媒体或复用音乐。已有研究只有在作品版本、观看范围、证据和需求仍适用时才复用；原文或附件改变后重新检查受影响判断。
