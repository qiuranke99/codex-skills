# 报告格式与完成条件

以用户能直接修改原稿为目标，按复杂度缩放。正文可以直接在聊天交付；长稿可另存用户要求的文档。不要为一次简短审查强制生成多个清单或评分表。

## 最小可用报告

1. **结论和优先问题**：写清本次提示词校对范围、当前输入版本，以及最影响成片的问题；短稿无需凑足三至五项。不要把尚未看见的实片风险写成事实。
2. **参考依据（仅本轮要求时）**：逐条给作品与来源、适配关系、实际观看/听音范围、关键时间码和可借鉴机制。附加研究不足时说明缺项；默认校对省略此项，不追要影片。
3. **逐镜检查**：覆盖所有镜头，保留原镜号/时间与原文定位，可用短段落或表格。按发现关联参考职责与起点、关键物理过程、动静区域和景别过程，不强制填满大表。无明显问题的镜头也给简短理由；原文没写的起止景别或物性标为“未明确”，不替用户补写成已经存在。
4. **全片与声音**：镜头/景别比例、镜长分布、结构和剪切节奏、实际转场两端、音乐段落与声音落点。统计写明区间、分母、计数和估算范围；名义出镜时长只能描述安排，不能作为品牌、文字或动作已被看清的实测结果。
5. **修改顺序及示范**：先处理硬冲突、音乐缺失、无景别变化和弱运镜，再处理幅度、重复、节奏与转场。对最关键的薄弱镜头给可直接采用的局部示范；完整重写须在当前请求范围内。
6. **实际检查与未验证项**：说明完成的文字检查及影响结论的缺失附件。实际生成效果未验证可简述一次，无需逐镜重复“没看过影片”；要求参考研究时再说明实际看听范围。

单项诊断应形成可追溯链条：

`S03 / 00:04–00:06 / 原文“近景，轻后撤” → 弱运镜且结束景别未明确 → 可能维持近似静帧 → 建议改为细部特写拉开至完整主体并揭示空间关系 → 参考 B 约 00:07–00:10 的尺度展开；实际路径和时长按本项目验证。`

如果上述参考未实际观察，就不能填“参考 B”或时间码；应直接标为审查者设计建议。

## 状态和完成

使用清楚的文字状态，无需伪精确综合评分：

- **必须修改**：与当前硬要求冲突，如实际使用禁用弱运镜、无景别变化且无当前用户确认的例外、缺失音乐设计。
- **优先改善**：已有有效设计，但幅度有限、镜头冗余、节奏单调或参考显示出明显更优路径。
- **生成风险**：有依据的模型执行不确定性，例如关键帧微动画、并镜和过载；说明触发条件。
- **待核实**：附件、视听证据、模型能力或约束缺失。

参考职责、动作起点和材质/结构之间已有明确文字矛盾，可直接定位并要求修正；若判断依赖尚未看见的图片、未知物性或模型内部机制，就保留对应的不确定性。注明依据是实际看图、用户文字说明、已核实能力还是设计推断，不把参考未见和整份文本校对未完成混为一谈。

例外须能定位到当前用户要求或仍有效的用户确认。待审稿自行写“机位固定”只是审查对象，不自动构成免检依据；确认过的约束则保留，仅在确无景别变化时说明该例外，不把固定机位自动理解为全画面定格。最新要求确有冲突时报告冲突，不静默选择一方。

完成提示词校对意味着已按范围处理所有镜头、全片与音乐并如实报告发现，不意味着原稿没有问题。提示词是唯一必需输入；没有影片、音频或参考研究不妨碍完成这项工作。文字中的缺写、矛盾、禁用动作可直接裁决，有条件的执行风险保留条件，不等成片才判断。

用户另行要求参考研究时，将“提示词校对完成情况”与“附加研究完成情况”分开：后者需要本轮目标数量及真实观察证据。未完成的附加研究不能宣称完成，也不把已完成的文本校对降格。具体生成效果只有对应媒体才能验证，这是效果核验边界，不是要求用户先交影片。

## 修订回查

原稿、审查者的局部示范和完整修订都用同一原始要求回查。逐项说明原问题是已在文字中修正、仍有风险还是证据不足；增加大幅动词、角度数字或起止景别不等于修法成立。若原提示词已变化，旧扫描的哈希与行号不得继续当新版本证据。

把以下条件放在同一时间线上，按问题需要说明，不另设必填大表：

- **输入与物理过程**：参考只承担已确认的职责；起点、接触/受力与结束状态连续；修法没有更换材料性质，也没有把几何稳定误写成禁止整体位移、透视变化或正常表演。补到位动作后重新检查时间与景别，不靠扩时或微运镜掩盖冲突。
- **任务与可见阶段**：给定镜长内，主要事件、信息何时可见、主辅运动和镜内景别路径能否共同成立。名义出镜一秒，不等于目标信息可读取一秒；文字只能预判可读压力，实际可读性须由对应成片验证，不设统一停稳秒数或要求每镜停稳。
- **实际交接点**：以切出那一刻的末态、下镜切入的首态及声音落点核对衔接。镜中途出现过相似图形，不代表实际切点形成准确匹配；图形关联可以保留，但不能冒称精确匹配剪辑。声音可跨切、提前或延后进入，无需每切踩拍。
- **音乐的三个判断**：音乐设计是否充分、由生成入口或后期负责执行、跨段音轨是否连续分别报告。已有完整音乐设计却未绑定音轨，问题是执行或连续性证据不足，不能判成没有音乐。同 BPM、调性、动机不证明两段是同一音轨；有连续母轨及明确时间映射时也不应重复要求重配。执行能力未知则标明待核实，文字方案不等于已生成或已听过。

**短镜修法回查**：一镜仅 0.6 秒，任务是传达目光并交接到下一镜圆形产品。把固定面部近景改成“大幅推进至单眼极近景，再绕行到侧脸”虽增加了运动，仍须检查目光在哪一阶段可见、实际切出是否仍是眼部，以及下镜首态和声音落点是否承接。先收敛附加运动，保留必要尺度变化与原任务；若镜长、信息和衔接仍不能兼容，点明具体冲突并提出有限取舍，不能擅自扩时、减镜，也不能以短镜为由自动免检。

**跨段声音回查**：两段各自生成音乐，即使都写相同 BPM、调性和主题，也只约束了相似性。可以判定文字音乐设计充分，同时保留连接处的旋律位置、起音、相位或尾音衔接待核实；提出适合本片的音轨绑定或交接方案，不把统一后期配乐设成所有项目的必选路线。

维护本包时用不同题材、镜长、约束和音乐方案的提示词前向验证：既记录应发现的问题，也记录应保留的有效设计；给执行代理原始请求，不预先提供预期答案。机械脚本与独立行为测试分别报告；固定影片不证明校对能力，测试通过也不等于生成效果或用户接受。
