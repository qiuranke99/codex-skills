# 报告格式与完成条件

以用户能直接修改原稿为目标，按复杂度缩放。正文可以直接在聊天交付；长稿可另存用户要求的文档。不要为一次简短审查强制生成多个清单或评分表。

## 最小可用报告

1. **结论和优先问题**：写清本次为完整审查还是文本初审、当前输入版本，以及最影响成片的三至五个问题。不要把尚未看见的实片风险写成事实。
2. **参考依据**：逐条给作品与来源、适配关系、实际观看/听音范围、关键时间码和可借鉴机制。参考不足或听音不可用时显著说明缺项。
3. **逐镜表**：覆盖所有镜头，保留原镜号/时间与原文定位。推荐列为“原文及起止景别｜变化幅度与事件｜问题/风险｜修正方向｜参考或约束依据”。无明显问题的镜头也给简短理由；原文没写起止景别则填“未明确”，不替用户补写成已经存在。
4. **全片与声音**：镜头/景别比例、镜长分布、结构和剪切节奏、转场、音乐段落和切点配合。统计写明区间、分母、计数和估算范围。
5. **修改顺序及示范**：先处理硬冲突、音乐缺失、无景别变化和弱运镜，再处理幅度、重复、节奏与转场。对最关键的薄弱镜头给可直接采用的局部示范；完整重写须在当前请求范围内。
6. **实际检查与未验证项**：哪些输入读过、哪些参考实际看听过、哪些附件缺失、哪些结论需要生成后验证。

单项诊断应形成可追溯链条：

`S03 / 00:04–00:06 / 原文“近景，轻后撤” → 弱运镜且结束景别未明确 → 可能维持近似静帧 → 建议改为细部特写拉开至完整主体并揭示空间关系 → 参考 B 约 00:07–00:10 的尺度展开；实际路径和时长按本项目验证。`

如果上述参考未实际观察，就不能填“参考 B”或时间码；应直接标为审查者设计建议。

## 状态和完成

使用清楚的文字状态，无需伪精确综合评分：

- **必须修改**：与当前硬要求冲突，如实际使用禁用弱运镜、无景别变化且无用户锁定例外、缺失音乐设计。
- **优先改善**：已有有效设计，但幅度有限、镜头冗余、节奏单调或参考显示出明显更优路径。
- **生成风险**：有依据的模型执行不确定性，例如关键帧微动画、并镜和过载；说明触发条件。
- **待核实**：附件、视听证据、模型能力或约束缺失。

完成审查意味着已按范围处理所有镜头并如实报告发现，不意味着原稿没有问题。完整的参考支持审查要求达到本轮参考目标、逐项给出真实观察、音乐与全部镜头均已检查；材料受阻时可交付有用初审，但未完成部分保持未完成。

文本初审可确认缺写、矛盾、禁用动作等；不能因缺少参考就不报告这些问题。也不能以文本初审代替用户要求的多片视听研究。

## 修订回查

用同一原始要求比较修订前后，逐项说明原问题是已在文字中修正、仍有风险还是证据不足。重写后的新矛盾也要检查。不要只统计消失的词或增加的专业术语。若原提示词已变化，旧扫描的哈希与行号不得继续当新版本证据。

维护本包时可使用 [逐镜判据与示例](shot-review.md) 的合成案例验证以下行为：负面约束不误报；大幅但无法执行的镜头仍被指出；慢速大跨度不被误杀；锁定定格不被改写；无音轨参考保持未验证；一个作品的转载不能凑成多条。机械脚本自检无法替代这些语义判断或真实看片。
