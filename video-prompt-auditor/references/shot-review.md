# 逐镜判据与示例

先看原文意图、当前用户要求及约束来源，再裁决。以下是本 Skill 的审查标准和合成示例，不是实片验证结果，也不是适用于所有电影的普遍美学定律。

## 先辨认真正锁定

原稿自称“固定”“必须”仍是待审内容，不能自动当成用户已确认的审查豁免。保护当前用户明确要求及其仍有效的已批准约束；记录影响裁决的来源。仅原稿写固定机位时仍照常检查，确无景别变化则指出并给修正建议；用户另行明确保留时，说明冲突或例外，不偷偷改动。来源不明且影响修法时标为待核实，不能自行认定已获豁免或已获解除授权。

固定机位、固定焦距、主体静止与全画面定格不是同一约束。先检查允许变化的维度；不能把“固定机位”扩大成全部静止，也不能用主体运动或变焦绕过用户明确锁定的构图、尺度或定格。

## 把形容词还原成可观察变化

| 检查项 | 有效写法应交代 | 常见缺陷 |
| --- | --- | --- |
| 景别 | 起始 → 关键中段 → 结束景别、比较对象及占画关系 | 只看首尾漏掉中途变化；多个镜之间有远近但单镜无变化 |
| 摄影机 | 相对于主体与环境的路径、方向、幅度、时间/速度发展 | 只写推拉摇移名称；把同尺度环绕当大幅景别变化 |
| 主体/事件 | 起始状态、行动或物理过程、结果及新信息 | 只描述材质、漂亮姿态；物体原地漂动无进展 |
| 构图/空间 | 角度、前中后景、视差、遮挡与注意力转移 | 静态图平移/放大被描述成真正空间穿行 |
| 切点 | 事件完成或转换的明确时刻、下一镜接续条件 | 只写“丝滑转场”，两侧无动作/图形/方向条件 |
| 时长 | 同一时间窗口内可完成的主要事件和运动 | 一秒内多段大位移、旋转、变焦和复杂动作互相抢时间 |

“大幅”优先以可见结果说明，例如环境全景推进至人物面部特写，或产品细部极近景拉开至完整产品与场景关系。可补主体占画高度等近似量帮助执行，但不虚构原文数值，也不把某个统一百分比当所有题材的及格线。

**尺度、角度、视差、信息揭示分别评价。** 同尺度环绕可以揭示另一面，横移可以产生遮挡变化，二者都不能仅凭新信息或背景移动充当大幅景别变化。反之，有效景别变化也不自动证明真实空间穿行。

核对摄影机与主体的相对距离、焦距或裁切变化及主体运动：摄影机与主体同向跟随、变焦补偿等可能抵消尺度变化，不能只凭位移距离或“推进”动词判定。关系不明时指出缺写，不虚构数值。物理位移、光学变焦、主体接近或数码裁切都可能改变尺度；数码变焦不自动判错，但不能冒充要求中的真实透视变化，更不能靠物体伸缩、脸部变形或背景拉伸制造变化。

比较对象可随连续揭示从细部交接到整物、人物或环境，应写清交接阶段与关系；不要求同一物体始终完整在画面。首尾尺度相同也须检查全程，不能漏掉中途已发生的大幅展开或收拢。

## 硬问题、偏好与风险分开

- 实际正向指令中的“微横移”“小幅升高”“轻后撤”“缓慢升高”和语义相近的弱动作：列为本审查标准的必须修改项。句子“禁止微横移”是约束，不是错误动作。只换形容词或删禁词不算实质修正，扫描命中只能定位。
- 分别裁决**主运动与辅助补偿**。已有明确大幅主运动时保留其有效设计，修正辅助弱指令的功能、路径与可见结果；辅助只需维持主体位置或避开遮挡时写明跟随关系，无任务则删除。不能因辅助措辞弱就判整镜只有微动画，也不要求每个辅助轴都独立大幅运动。整镜仅有弱动作时需重建主路径与景别发展。
- 无景别变化、未交代变化，或用主体微动代替镜内变化：逐镜明确指出；真正用户锁定的例外按前述来源处理，不能自行用短镜或艺术理由豁免。
- 已有明确但幅度有限的变化：优先改善。最新偏好是镜内最好有大幅变化，因此提出实质升级方案，但不能假称每镜都已被要求极端远近切换。
- 慢速度和小幅运动分别评估。长时间慢速大跨度推进可以明确改变景别；不要将所有慢镜头或慢动作列为禁用。
- 没有音乐设计：必须补；泛泛一句 BGM：设计不足。当前用户明确无音乐时保留。
- 漏镜、并镜、形变等模型行为：属于有依据的风险。只有看到实际对应版本媒体才能报告为已发生。

## 修法自身也要过逐镜检查

在**原时长**内，把原镜头任务、信息实际可见阶段、主运动与辅助动作、切出末态和下一镜首态放到同一时间线上。画面中出现产品或文字不等于已完成识别任务；检查运动、遮挡、焦点、尺度和注意力变化是否留下相应观察机会，不从文字宣称已测得可读性，也不强求每镜停稳。

新增大幅运动后重新核对原事件是否仍可见、主辅动作是否争抢时间，以及实际相邻切点的方向、构图、动作和音乐关系。匹配条件应取前镜切出末态与后镜切入首态，不能拿镜内别的阶段代替。下一镜资料缺失时保留衔接待核实，不能编造接法已成立。

短镜仍须检查景别变化；短本身既不是豁免，也不能证明必然失败。修法优先将任务与揭示合并到一条有主次的路径，去掉建议自行新增的支线。原任务、时长、锁定与变化仍不能同时成立时，报告具体冲突和有限取舍，不自行扩时、减镜、删原任务或更换制作路线。

## 关键帧微动画风险

检查以下组合，而非看到“关键帧”三个字就判错：

- 每镜依次绑定一张图，同时要求全程保持相同构图、主体占画尺度与视点。
- 摄影描述只有微推、轻摆、浅幅漂移；缺少明确起止状态和事件发展。
- 大幅移动摄影机却要求背景、透视、遮挡关系逐像素不变。
- 参考图负责身份，却被误用来锁死整段时间；美术参考被当成必复刻首帧。
- 多镜时间表写得密集，但没有可分辨的镜头边界、动作终点和下一镜开头。

修正方向：明确各附件负责身份、风格、构图或时间中的哪一部分；保留真正锁定的内容，写清允许变化的维度与镜内事件。只提出参考职责调整建议，不擅自删换已锁定附件。

## 合成裁决示例

这些示例仅说明诊断与写法，未经过视频生成；时长、幅度须按具体作品调整。

1. **原稿固定 / 用户确认固定**：同一句“机位固定、产品始终近景”仅在原稿出现时，报告无镜内景别变化并建议修正；若用户明确确认保留该近景与机位，则保留并列明锁定例外，不假称已有变化。仅确认固定机位时，仍需判断主体运动等是否允许。

2. **主强辅弱 / 整镜弱**：四秒内从瓶盖纹理极近景拉至完整瓶身与台面关系，另写“小幅升高”。主拉远可保留，辅助需修正；若它只是防止瓶盖出框，可写“退镜中云台随瓶盖位置俯仰跟随，使瓶盖保持画面上部”，而不另加大幅升降。若整镜只有“产品近景微横移”，则需建立实质路径与揭示，例如沿瓶身斜后方拉开、经过瓶肩显露标签、以完整瓶身与台面关系切出，并按实际下一镜核对衔接。改成“宏大横移”却不改变结果仍不合格。

3. **慢速跨度 / 角度与视差**：八秒从场地全景推进至人物面部特写，不因“慢速”否决，仍核对相对距离与可执行性；环绕半周但主体始终等大，只能先确认角度与背景变化，不能记为大幅景别变化。推进例若同时写主体向后等速退去，还须检查相对距离与焦距，不能仅凭摄影机推进认定尺度会变。

4. **中段展开 / 参照交接**：特写拉至全景再回到特写，有明确中途大幅变化，不判为“首尾相同所以无变化”；从扣环细部拉开到完整手袋、再到持袋人物与街道，允许比较对象逐步交接，但要交代连续揭示的关系，不能只罗列景别词。

5. **短镜候选 / 修法过载**：0.6 秒从搭扣特写随开盖拉至完整盒，原任务只需辨认“打开”，应检查该动作在运动中的可见阶段及下镜接续，不能仅凭短就否决或免检。若修法在同一时段又追加读清三行小字、转到背面和另一项动作，应指出新增任务竞争，收回新增支线并复查原任务；不凭大幅动词宣布可行，也不直接断言当前模型必失败。

6. **音乐缺写 / 有设计**：“高级、有节奏的 BGM”仍不足；稀疏脉冲起场、展开段加密、完整揭示前留停顿并在揭示完成时落重音、结尾抽离节奏，是可继续核对时间线的设计。音乐执行入口、实际听音与成片效果仍分别验证，不要求每个切点踩拍。
