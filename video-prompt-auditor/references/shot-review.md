# 逐镜判据与示例

先看原文意图与锁定，再裁决。以下是本 Skill 的审查标准和合成示例，不是实片验证结果，也不是适用于所有电影的普遍美学定律。

## 把形容词还原成可观察变化

| 检查项 | 有效写法应交代 | 常见缺陷 |
| --- | --- | --- |
| 景别 | 起始与结束景别、主体占画关系、关键中间揭示 | 始终近景，仅“轻轻动”；多个镜之间有远近但单镜无变化 |
| 摄影机 | 相对于主体与环境的路径、方向、幅度、时间/速度发展 | 只写推拉摇移名称；把同尺度环绕当大幅景别变化 |
| 主体/事件 | 起始状态、行动或物理过程、结果及新信息 | 只描述材质、漂亮姿态；物体原地漂动无进展 |
| 构图/空间 | 前中后景、遮挡揭示、透视与注意力转移 | 静态图平移/放大被描述成真正空间穿行 |
| 切点 | 事件完成或转换的明确时刻、下一镜接续条件 | 只写“丝滑转场”，两侧无动作/图形/方向条件 |
| 时长 | 同一时间窗口内可完成的主要事件和运动 | 一秒内多段大位移、旋转、变焦和复杂动作互相抢时间 |

“大幅”优先以可见结果说明，例如环境全景推进至人物面部特写，或产品细部极近景拉开至完整产品与场景关系。可补主体占画高度等近似量帮助执行，但不虚构原文数值，也不把某个统一百分比当所有题材的及格线。

物理位移、光学变焦和主体接近都可能形成尺度变化，应明确机制。数码变焦不自动等于糟糕；当它被拿来冒充要求中的真实透视/空间变化时指出差距。不能靠产品自我伸缩、脸部变形或背景拉伸制造所谓景别变化。

## 硬问题、偏好与风险分开

- 实际正向指令中的“微横移”“小幅升高”“轻后撤”“缓慢升高”和语义相近的弱动作：列为本审查标准的必须修改项。句子“禁止微横移”是约束，不是错误动作。扫描命中只能定位，不能代替判断。
- 无景别变化、未交代变化，或用主体微动代替镜内变化：明确指出。用户锁定的静止落版/固定机位等作为当前约束保留，说明与偏好的关系，不能静默改动。
- 已有明确但幅度有限的变化：优先改善。最新偏好是镜内最好有大幅变化，因此提出实质升级方案，但不能假称每镜都已被要求极端远近切换。
- 慢速度和小幅运动分别评估。长时间慢速大跨度推进可以明确改变景别；不要将所有慢镜头或慢动作列为禁用。
- 没有音乐设计：必须补；泛泛一句 BGM：设计不足。当前用户明确无音乐时保留。
- 漏镜、并镜、形变等模型行为：属于有依据的风险。只有看到实际对应版本媒体才能报告为已发生。

## 关键帧微动画风险

检查以下组合，而非看到“关键帧”三个字就判错：

- 每镜依次绑定一张图，同时要求全程保持相同构图、主体占画尺度与视点。
- 摄影描述只有微推、轻摆、浅幅漂移；缺少明确起止状态和事件发展。
- 大幅移动摄影机却要求背景、透视、遮挡关系逐像素不变。
- 参考图负责身份，却被误用来锁死整段时间；美术参考被当成必复刻首帧。
- 多镜时间表写得密集，但没有可分辨的镜头边界、动作终点和下一镜开头。

修正方向：明确各附件负责身份、风格、构图或时间中的哪一部分；保留真正锁定的内容，写清允许变化的维度与镜内事件。只提出参考职责调整建议，不擅自删换已锁定附件。

## 对照示例 v1

这些示例仅说明诊断与写法，未经过视频生成；时长、幅度须按具体作品调整。

**弱写法**：`S01，0–4秒，产品近景，摄影机微横移，保持原图构图。`

**诊断**：弱运镜；起止均为近景；“保持原图构图”与视点变化可能冲突；没有事件或新信息。

**局部修正示范**：`S01，0–4秒，从瓶盖纹理极近景起步，摄影机沿瓶身斜后方持续拉开并抬高视点，经过瓶肩时显露完整标签，结束于完整瓶身与台面环境的中全景；产品几何、文字与位置保持稳定，构图和透视随位移改变。在瓶底及台面关系完全显露时切入下一镜。`

示范提供了尺度、路径、信息揭示和切点；它不自动证明所给四秒或当前模型足以完成，需要对照真实参考和入口能力判断。

**伪修正**：把“微横移”改成“宏大而高级的横移”，起止构图不变。仍需修正。

**可成立的慢运动**：八秒内从场地全景连续推进至人物面部特写，中途穿过前景并揭示人物视线目标。须评估空间距离与可执行性，不能只因“慢速”二字否决。

**锁定例外**：用户明确要求最后一秒定格品牌落版。保留这一秒，改善前一镜如何完成揭示与收束；在报告中注明已锁定定格，不伪称其有大幅变化。

**音乐不足**：`全片使用高级、有节奏的音乐。` 缺少节奏发展、段落与画面关系。

**声音修正示范**：`开场以稀疏低频脉冲建立拍感，展开段加入短促打击并提高密度；产品完整揭示前留短暂停顿，在揭示完成时落下明确重音；结尾抽离节奏，仅保留短尾音随落版结束。具体切点按镜头时间线对齐，保留需要呼吸的非踩拍镜头。` 是否由生成入口或后期执行要单独说明。
