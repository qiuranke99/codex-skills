# 行为测试与独立复核

仅在维护 Skill 或用户要求验证时使用。日常逐镜审查无需跑维护测试。

## 核心校对能力与可选工作分开

- 定位器：运行 `python scripts/test_scan_prompt.py`，检查候选定位、哈希、状态与安全输出。通过不代表导演判断正确。
- 导演语义：使用 [合成输入](../tests/behavioral-inputs.json)，由未参与改稿的代理按真实请求执行。只给输入、当前 Skill 和必要原始材料，不给旧结论或 [裁决标准](../tests/behavioral-rubric.json)。输出放在任务目录，封存后再依据标准评审。
- 默认完成行为：用没有“只做文字”等额外提示的普通校对请求，检查仅凭提示词是否覆盖全部镜头、音乐和风险并完成交付，不追要影片或自动查参考。跨题材、镜长、真锁定与稿内伪锁定、充分与不足的设计都要覆盖，不能只重复某一条片子的结论。
- 输入与物理判断：用成对案例区别首帧与身份/影调参考、跳过到位动作与合法连续行动、刚体形变与整体运动、未知物性与明确材质矛盾。检查局部克制动作是否仍保留大幅景别变化，是否拒绝未经证实的模型配额或机制断言。实际看图测试须提供原始合成图并记录视觉工具观察；仅图像文字说明只能算文本测试。
- 合成看图素材：维护者按 [几何规格](../tests/image-fixtures.json) 在任务目录绘制两张无字 PNG，逐案绑定相应 `asset_id`、路径和摘要。不给前向执行者绘图规格或另一案的图片说明；每案实际打开本案图片后再裁决。绘图结果与执行记录留在任务目录，不提交到本包；缺图或没有视觉工具观察只能记该视觉测试证据不足。
- 可选参考研究：只有用户要求验证这项能力时，才实际完成相应观看与听音。合成案例、静帧或文字视听描述不能冒充实测；单条固定影片也不能证明通用校对能力。它不是核心文本校对的验收门槛。
- 生成效果：只有对应提示词版本的实际视频可验证运动、读取与声画执行；这不属于默认文本校对验收，文本测试通过不代表已生成或用户已接受。

## 执行与裁决

记录被测包版本/文件摘要、输入版本、代理实际运行参数与其是否参与改稿。语义执行者可以读取 Skill 中正常审稿所需的规则和示例，但不提前读取测试答案；若已暴露答案，记录污染并另换未暴露的执行者或新案例，不能称为独立前向测试。

按每个案例要求发现的问题、需要保留的有效设计以及不可声称的事实裁决，不做关键词命中评分。结果为通过、失败或证据不足，并引用执行输出中的具体依据。既检查漏判，也检查过度改写、私自豁免、假定视听已完成和把修法风险写成已发生失败。

合成输入中的用户要求与待审稿分开；案例可明确限定文字范围，也须包含不带这种限定的默认请求。默认提示词校对可以独立完成；用户另行要求多片研究时，则不能以文字测试冒充附加研究已完成。

失败时先定位是规则歧义、执行偏离还是样例事实不足，只作对应的小范围修改。复测失败案例和受影响的邻近案例；别用一轮机械脚本或作者自检替代独立复核。已有正确判断优先保留，不为通过测试增加通用景别倍数、停稳秒数或每切踩拍要求。
