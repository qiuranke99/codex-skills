# 参考输入职责与动作起点

本资源检查参考图的约束范围、时间状态与动作衔接，补充逐镜审查，不替代景别变化、弱运镜、剪辑和音乐检查。以下示例均为合成文本案例，没有生成或观看对应影片。

## 先登记职责与证据

- 职责依据本轮用户声明、仍有效的确认或明确选定的输入模式；不能凭文件名、上传顺序、画面内容或“参考图”三个字猜测。
- 区分用户锁定与稿件的执行设计。待审稿自称“首帧”可接受文本一致性检查，但不能据此宣称用户已锁定，或入口已实际绑定该图。
- 仅“图生视频”“多图参考”等宽泛名称不足以证明某图就是首帧；涉及入口如何解释图像时，依据已知模式或当前官方说明，未知则标明。
- 一图可以承担多项职责；逐项写出作用范围，不强制每种职责各有一图，也不把一项职责自动扩展成其他职责。
- 可访问的图片须用可用视觉工具实际打开后再描述。逐张记录已看、未看或无法访问，不以文件存在、名称或他人描述代替观看。
- 只有提示词、缺图或图无法访问时，仍完成全部镜头、全片结构及音乐的文本校对；写清“图像事实待核实”，不能声称已看到姿态、材质或光位。
- 登记可直接放进现有逐镜记录：图引用、职责、依据、对应时刻/区间、锁定内容、允许变化、观看状态。不新增必交表单或附件门槛。

## 各职责究竟约束什么

| 职责 | 应检查的约束 | 不应自行推导的锁定 |
| --- | --- | --- |
| 首帧或时间状态锚点 | 明确时刻的可见姿态、位置、接触、支撑、遮挡及画面状态 | 整段冻结；从单张图读出不可见过程或精确摄影参数 |
| 人物身份 | 用户指定的人物外观及识别特征 | 姿势、表情、视线、手的位置、服装或灯位均永远不变；这些须另有声明 |
| 产品身份 | 外形、结构、标识、色彩及被明确指定的产品事实 | 拍摄角度、画中位置、占画尺度、持握方式自动锁定 |
| 材质 | 图中可辨的表面、质感或被明确指定的材料状态 | 单图证明黏度、内部结构、受力规律或任意形变过程 |
| 影调与用光风格 | 明暗关系、色彩、软硬、反差和高光特征等目标 | 精确物理灯位、逐像素高光位置或全程相同阴影 |
| 构图 | 声明适用时刻/区间的视点、尺度、位置与画面关系 | 仅给一张构图图就锁死整镜；构图参考自动成为首帧 |

没有时间锚定的身份、产品、材质或风格图，不负责规定动作从哪个姿态开始。用户另行锁定姿态、服装或构图时，应增加相应约束，不能用“仅身份参考”将它解除。

首帧约束时间零点；中间帧约束指定中段；尾帧约束到达状态。后两者要求核对到达路径与时间，不自动把它们的姿态搬到开头。若用户明确要求某状态覆盖区间，则按该区间检查。

一图多职责时按职责拆解冲突，例如同图既是产品身份又是首帧，保持产品结构与允许摄影机离开首帧视点可以同时成立。冲突须指向具体状态、时刻和指令，不能笼统归咎于“参考太多”。

## 按时间核对动作起点

1. **认定真实起点。** 找到负责本镜初始状态的图或明确文字；没有初始锚点时不凭身份图补造一个。首帧是否实际绑定未知时，先按稿件声明作条件审查。
2. **提取可见状态。** 记录主体姿态、手/工具的位置、与谁接触、由何处支撑、谁遮挡谁，以及视角与可观察的明暗关系。看不见的部分留空，不臆测接触力或精确灯位。
3. **展开原文时间线。** 写成“起点 → 进入动作 → 接触/状态改变 → 结果”，标出原文是否把结果写成第一时刻已经成立，是否跳过必要过渡。
4. **区分跃迁与运动。** 合法移动会改变位置和姿态；有明确路径、先后与容纳时间时，不能因为它离开首帧姿态就判冲突。同一时刻要求互不兼容的状态是矛盾；过渡条件未交代应标缺写或条件风险。
5. **对齐已有时长。** 将过渡、主要事件、摄影变化与可见结果放进原时间窗口；不能只加“自然地”“连续地”就宣称动作够时。短时长是检查条件，不是必失败结论。
6. **回查锁定与邻镜。** 修法保留真正锁定的参考、动作任务和时长，核对切出末态与下镜切入首态。相邻镜缺失时标为待核实，不虚构已完成匹配。

起点信息不足时可报告“缺少动作进入阶段”或给条件性建议，不把缺写直接升级为已发生的跳帧或模型错误。

## 接触、支撑、遮挡和摄影关系如何演化

- **接触：** 起点是否已接触；若尚未接触，何时靠近、首次接触、滑动或离开。不能让涂抹、按压等接触动作在主体仍远离目标时已经完成。
- **支撑：** 起点由手、台面或其他物体承托；若转移支撑，交接与释放的先后是否清楚。这里只核对状态衔接，受力与材料响应另按物理判据审查。
- **遮挡：** 摄影机或主体移动后，前后关系怎样变化、原本被挡的信息何时出现。不能既要求保留起点遮挡，又声称同一时刻已完整展示被挡部分。
- **视角：** 区分主体转动与摄影机移动；视点变化可以改变可见面、透视、遮挡和占画尺度。身份保持不等于这些关系必须不动。
- **光线：** 分清世界中的光源约束、画面的影调目标和表面高光位置。相机或物体移动可能改变反射与可见阴影，不能把高光移动一律当作灯位违规。
- 若要求实际灯位改变、重新受光或从遮挡区走出，应交代何时及因何变化；不能以“影调参考允许变化”为由解除用户真正锁定的光线条件。
- 不要求百分之百冻结，也不接受万能的“物理顺延”承诺。逐项说明哪些状态保持、哪些发生变化，以及相关动作和摄影条件。

## 冲突定位与修法边界

每项发现至少连接：镜号及原文 → 图的职责与来源 → 已见事实或待核实内容 → 冲突时刻 → 具体修法。把原文矛盾、信息缺写、条件性生成风险分开。

优先在原窗口内明确进入动作、接触阶段和摄影关系，减少建议自行追加的任务；但不能为补过渡而偷偷删掉原镜任务、缩短锁定动作或改掉结尾。

若已锁定的首帧、立即发生的主动作与时长无法兼容，明确指出需要取舍的是哪一项，例如允许动作稍后开始、放宽首帧状态或调整时长；这些是待用户选择的修改条件，不是已经获准的改动。

不擅自更换、裁掉、重做或改派已锁定参考，不以换图掩盖时间矛盾。职责来源不明且影响修法时，给出对应分支并保留待核实。

不把这类冲突推断成“潜空间”“注意力分配”等已证实模型根因；不宣称所有供应商都必然冻结、跳变或忽略某图。文本诊断成立与生成表现仍分别记录。

## 正反例

### 1. 首帧手在锁骨：状态跳过与合法移动

- **有冲突：** 用户指定该图为首帧，实际看到手停在锁骨；原文却写“第一时刻手掌已贴住脸颊并向外推开”。同一初始时刻的手位不兼容，且从锁骨到脸颊的进入动作被跳过。
- **可兼容：** 原文明确“从锁骨抬手，接触脸颊后再向外推开”，已有时长能容纳过渡与主动作时，不因手移动判错。仍需检查动作可见阶段、景别过程与执行风险，不能仅因补了动词就判全镜通过。
- **修法限制：** 若时长已锁定且容不下完整动作，报告具体取舍；不能擅自把首帧改成手在脸颊，或直接增加镜长。

### 2. 身份图的姿态：越界锁定与正确使用

- **误判：** 用户只指定图片保持人物身份，审稿者因图中双手下垂，便认定提示词的抬手动作“违反首帧”；或因图中是侧脸，就禁止摄影机转到正面。参考职责没有提供这些时间与摄影锁定。
- **正确判断：** 保持指定识别特征，按提示词检查抬手的起点、过程与结果；可以改变姿态和视角。若用户另声明“本图同时作首帧”，才把已见姿态纳入初始状态检查。
- **无图分支：** 图片未能查看时，只能说“若该图确为首帧且手位如所述，则存在起点冲突”；不能写成“我已看到手位冲突”。

### 3. 起点遮挡与影调：相互矛盾与连续揭示

- **有冲突：** 已核实的首帧中手遮住产品标签，原文同时要求“从第一时刻完整读清标签”且保留手的原遮挡关系；应定位展示任务与首态的冲突。
- **可兼容：** 在原时间内明确移手后显露标签，摄影机沿既定路径揭示产品，保留目标影调并允许反射随视角演化；实际可读性及运动效果仍待媒体验证。
- **不能偷换：** 用户若另锁定手不得移开，不能擅自执行上述修法；须核对允许的视角是否有可见路径，无法兼容则提出具体取舍。
