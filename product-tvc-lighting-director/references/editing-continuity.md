# 剪辑节奏与连续性

按镜头要传递的信息选择方法。下列两端条件、时间安排和示例是本 Skill 的创作与执行建议，不是所有高级 TVC 都必须遵循的行业标准；用户明确锁定的顺序、镜数和剪辑形式优先。

## 先设计信息与能量，再分配镜头

1. 用一句话确定全片视觉命题，写清观众先认识什么、随后发现什么、哪次变化改变预期、最后记住什么。起、承、转折、高潮与收束是叙事功能，不强制对应五个镜头。
2. 从 30 秒中先预留最终稳定停留，再给产品辨认、卖点关键过程和物性变化分配足够时间。用剩余时长组织进入、动势发展和切换；不得把时长平均分给输入关键帧。
3. 为每镜指定一个主事件、一次可见进展和一个切出理由。复杂事件需要完整铺垫时合镜；新视角确实揭示新信息或带来有意义反差时拆镜。不能靠增加切点掩盖动作未完成。
4. 组合长短镜、景别跨度、运动方向、动作峰值与辨认窗口。大幅运动可以经过积蓄、加速、峰值和减速；相邻镜不必都从静止开始，也不必都在结尾减速归零。
5. 比较至少两条内部节奏路径，例如“克制揭示后集中释放”和“冲击开场后深入解释”。选择服务当前产品的一条；例子不是每次照搬的时间配方。不以全程高速、每拍必切或转场数量代替导演判断。

**单镜约束：**用连续的远近变化、视角转换、焦点接力、料体事件与速度阶段产生镜内节奏。切换注意力时明确上一个事件如何退出、下一个事件何时接管。用户要求真实连续一镜时，不暗藏剪辑、时间跳跃、瞬间补料或产品状态复原；确实无法并存的锁定要求需要指出具体冲突。

## 切法与转场选择表

每个切点至少说明“前镜切出状态 → 连接依据及切点 → 后镜接入状态”。表中条件按需要选择，不要求每次输出全部字段。

| 表达目的与方法 | 可见写法 | 成立条件（两端） | 常见失败 |
| --- | --- | --- | --- |
| 动作中切镜 | 连续动作跨景别推进，保留动力 | 同一事件：前镜在动作未结束时切出，后镜从对应进度接续；匹配受力、运动方向、姿态与动作相位 | 前镜已经完成，后镜重新启动；同一滴料体出现两次 |
| 图形匹配 | 以轮廓、弧线或构图建立产品与料体的视觉联系 | 指定匹配形状的画面位置、占比、朝向及切点；跨对象时明示剪辑切换对象 | 只有“都是圆形”，却大小、位置全跳；把形似写成物理变形 |
| 方向 / 速度匹配 | 将动势从一个事件交给另一个事件 | 匹配屏幕运动方向和切点附近位移趋势；世界坐标相同不等于画面方向相同 | 突然反向、瞬停、速度骤降；相机追随抵消运动 |
| 推拉 / 旋转接力 | 放大远近跨度或角度变化，带着运动进入下一镜 | 写明切前景别、运动中心和接入景别；旋转需对齐画面旋向与相位，推拉需对齐视觉扩张或收缩方向 | 每镜重复同样推近；接力中无解释地穿过包装实体 |
| 景别反差 / 有意硬切 | 通过尺度或构图反差强调揭示、结果或情绪转折 | 切点有事件理由；后镜先让观众辨认关系，再承接动作 | 把随机角度跳变称为高潮；没看清卖点就切走 |
| 实体遮挡切 | 借真实遮挡隐藏画面连接 | 用已获准且不透明的实体覆盖需隐藏的画面区域；两端遮挡边缘、方向、速度及亮度关系可接，注明实际切点 | 未获准道具突然出现；遮挡不足；后镜从相反方向揭开 |
| 甩镜切 | 短暂方向性模糊承接高能转折 | 两端摇摄方向及模糊趋势一致，在模糊充分处切换并揭示清晰的新信息 | 整镜糊成拖影；用甩镜偷换产品；误把横移叫水平摇摄 |
| 光色匹配 | 用亮面、反射形状或色块接通不同景别 | 指定局部光色块的位置、覆盖范围和运动；下一镜保留可识别的连接特征 | 无来源全屏闪白；过曝吃掉标签；违反背景照明固定要求 |
| 时间省略 / 蒙太奇 | 压缩过程或从演示时刻切换至售卖展示 | 明确略过何段时间、已完成什么、下一镜处于哪个展示时刻；保留卖点所需因果证据 | 省略关键作用步骤后宣称结果；把过去与现在混成同一连续过程 |
| 叠化 | 温和改变观察层次或标示时间流逝 | 两端留出可叠合区域与剪辑余量；说明叠化占用的成片时间 | 两套包装、标签和料体重影；叠化掩盖身份变化 |
| 后期速度重映射 | 改变已拍或生成动作的播放节奏 | 区分源动作与成片速度；指定加速、减速区间及保留的辨认窗口，重新核算成片时长 | 把播放变速误写成灯光频闪；拖慢后总长超时；重定时伪影被当成真实形变 |
| 声音桥 / J cut / L cut | 用声音预告后镜或延续前镜情绪 | 仅有声音需求时设计。J：后镜声音先入；L：前镜声音延续至后镜画面；写声音来源、起止和重叠范围 | 反写 J/L；给无声方案强加音轨；用音效宣称不存在的产品机构 |

匹配剪辑可以连接不同对象或展示时刻；动作连续性剪辑则须接续同一事件。不能因为视觉顺滑，就把两者的物理因果当成相同。分别核对相机与主体动势：料体动作可连续、相机可有意反向硬切，但要说清哪条运动继续、哪条发生反差，不能笼统写“承接既有速度”掩盖后拉转前推。

## 遮挡、作用过程与售卖状态

**透明物不是天然黑幕。**透明凝露覆盖镜头后仍可能透见、折射和变形背景；只有具备充分依据的厚度、浑浊度或真实不透明区域才能遮住接点。默认保留透明性，用折射形状、边缘弧线或方向做匹配硬切；不得为了藏切点擅改材质，也不得让镜头直接穿瓶壁。

**演示结果与完整包装可以出现在不同展示时刻。**料体已释放、结构已打开或内容物已减少时，后镜若需呈现完整售卖状态，写“通过剪辑切换至独立的售卖展示时刻”，并锁定同一 SKU 的正确完整状态。不能写“料体倒吸回瓶、已消耗内容物自动补满、已破坏结构自行恢复”。图形匹配负责视觉连接，不证明过程可逆；外部料体意象也不自动代表瓶内真实机制。

## 全片、分段和修订接口

全片只有一条成片时间线，镜号保持唯一且递增。相邻镜的成片区间首尾相接；叠化、速度重映射和末尾停留都计入 0—30 秒，不能在加总后另加。生成余量属于素材时长，另标实际保留区间；跨段重叠事件在成片中只保留一次。

分段时为每个连接写一条紧凑接口：

> 全片切点 / 两段局部时间；前镜产品数量、姿态、内容物量与动作阶段；相机位置、朝向、景别和焦点；屏幕动势；光影状态；连接依据；后镜接入状态；声音衔接（若有）；源素材余量及成片保留区间（若有）。

修改任一段后，从改动事件向后追踪至状态重新汇合处，同时检查进入该段的接口。重点核对：动作是否重播或遗漏、料体量是否跳变、结束姿态是否改变下一镜入口、镜头方向是否反转、动态光影是否跨段重启、声音是否错位、上传编号是否改指其他图片。同步改写受影响段的提示词和全片时间；不能只附一句“后段自然衔接”。

**落版计时：**默认最终稳定停留至少 1 秒，从产品主姿态、相机构图及品牌信息都完成落位时开始，至 30 秒结束。入场、继续推拉、转场或淡出不计入稳定停留。料体可保留不妨碍阅读的轻微余动；变化中的反射不得扫掉关键文字。按阅读量增加停留，不用最后一秒承载所有首次出现的信息。

## 两组坏例 → 好例

**1. 透明料体藏切点。**

坏：透明凝露冲满画面变成白幕，无缝变为产品，接着高级旋转。

好：凝露薄片沿左下至右上伸展，弧形边缘在画面中央升至半幅高度，保持透射和折射；弧线继续上移时硬切至瓶肩弧线，匹配位置、占比与上移方向。后镜从上移动势中接入上升环绕，逐渐揭示标签；这是形状与方向匹配，凝露没有变成包装。

**2. 分段改写与售卖落版。**

坏：前段改成料体完全释放，后段仍从释放开始，最后自动回满瓶；29—30 秒继续推近，算停留一秒。

好：前段修订后在全片切点完成释放；后段删除原来的重复启动，从已形成的外部料体展开状态接续，并相应调整其局部时间。展示结果后明确剪辑切至同款完整售卖状态；落版运动在 28.7 秒前完成，28.7—30 秒保持构图、产品主姿态与品牌信息稳定。回查相邻段的内容物状态和新切点，总长仍为 30 秒。
