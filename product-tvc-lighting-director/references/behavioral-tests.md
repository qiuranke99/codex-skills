# 维护时的实际试写与比较

只在创建、实质升级或发现退化时使用，常规提示词写作不跑整套评测。结构验证、语义试写与生成视频效果分别报告。

## 独立执行

作者拿真实请求、实际Skill路径和最小原始素材，实际打开全部指定输入，独立完成可复制提示词；不给预期答案、疑点、修复建议、别人的稿或评分。隔离目录保存原素材、请求、完整初稿/改稿、图片查看记录、包哈希与实际计数，客户材料及测试输出不入公共仓库。合成几何示意图可以测约束理解，但不能证明真实材质识别或光学效果。

比较母版与本包时采用相同素材/产品事实/用户锁定、同等正文限额、时长、平台合同和工具权限。作者独立，不让母版读衍生方法，也不给新版额外产品事实；各自必要的Skill资源不同是比较对象。隐藏版本身份后审阅完整稿，先看是否可执行和满足硬约束，再判哪里有提升、持平或退步，引用具体镜段因果，而不是词频、光效数、篇幅或“高级”字样。没有母版可用时可做本包独立行为验证，不把母版设成使用或验收依赖。

至少用有不同材质和控制条件的产品请求，比较：光影层次是否形成可读主次；是否显露真实材质差异；动态是否与相机/物体/料体协调；光路/时序是否可行；核心视觉事件是否有产品依据。少量案例只支持本次试写结论，不推导所有产品或模型的质量增益。若同预算不比母版好，要如实记录并修正已证实缺口，不能放宽新版要求宣布通过。

## 覆盖的真实请求条件

| 场景组合 | 审阅实际行为 |
| --- | --- |
| 清晰正面图、冲突标签关键帧、中途竖直姿态与多SKU状态图 | 权威正确；关键帧不锁全程；SKU/开盖/混合状态/实例分开；光影不能掩盖身份错误 |
| 大幅相机与主体、显著景别发展、必要品牌阅读窗 | 两类运动都成立，反射不淹没关键窗口；不以稳定照明为由把整镜缩成缓转；最终停留单独计时 |
| 金属+亮塑料、玻璃+凝胶、磨砂+乳霜等不同组合 | 明暗反射、粗糙度、透射厚度和固有色的可见响应不同；不把所有材质写成玻璃或铬 |
| 分别锁背景灯、背景画面、灯具位置、全部照明系统 | 不混淆自由度；选择合法驱动；固定条件不靠缩小运动满足 |
| 明亮/中调的影调参考，指定顺序与镜数 | 在用户顺序内形成节奏；高端不自动低调黑金；不用统一暗→亮→暗配方重复每镜 |
| 真正作用过程后回售卖状态 | 有因果/体积进度与切换展示时刻，光影不代替作用；不可逆不自动复原 |
| 一个事件跨独立生成单元，后续只改该事件时序 | 实际改写受影响接口与正文，保留其他有效锁定；光影及料体阶段不重复启动 |
| 9:16、16:9与1:1；不同图数/时长/字符限制 | 构图和运动包络按画幅发展；每段重新编号、自带身份与视觉；字符实际统计留余量，总30秒 |

允许一个请求覆盖多个场景，不为凑数量增加冗余全文。首稿后至少一次真实局部修改；审阅者查改动传播到重新汇合处，而非仅看“已同步修改”的回执。

## 反例审查

给独立审阅者失败片段和实际成稿，要求定位矛盾及最小修法：

- 大柔光箱所以反射边界一定极软；金属一律硬、玻璃一律软。
- 只因成片暗带移动，就断言移动黑旗；把负补光、黑反射、投影混作同一原因。
- 全部照明固定，却有独立灯强渐亮/移动遮光器；只固定灯位却断言任何反射板都已被用户锁死。
- 相机与产品各自大动，但白条永远粘在瓶中且声称自然反射；光源向右所以所有曲面高光也向右等速。
- 背景要求稳定，靠全局曝光脉冲制造高潮；所有层同时强亮导致无主次；每镜重放一次揭示却无新信息。
- 用透射光把磨砂变清玻璃、乳霜变透明液体、黑塑料变银色；点阵或发光替代功效证据；禁用所有发光抹掉真实指示灯。
- 光比正确但标签一直高速擦边/太小/背面；独立扶正文字；最后仍变焦/扫字却计为稳定停留。
- 透明胶遮成黑幕、多SKU融合、重复释放、不可逆过程自动恢复；下段重复同一光影相位；局部改动只改接口表。

审阅应区分Skill缺口、作者执行偏差、素材缺口和真实约束冲突；只为已证实的缺口加窄规则，重测受影响行为，不不断堆通用禁令。没有真实生成/逐时序视频检查与产品文字核对，最终不能称“视频效果已验证”。

机械工具 `scripts/test_check_delivery.py` 只测计数/时间算术。完整导演验收用[语义标准](acceptance.md)，不是关键词匹配。
