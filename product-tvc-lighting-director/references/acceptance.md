# 成稿的导演验收

按正文可执行的因果与观察结果判断，不能因出现“高级、机械臂、张力、稳定1秒”等词语就给通过。内部审完直接修正，最终只说明有意义的改动与仍存在的事实缺口。

| 判断面 | 应从成稿中证实 | 不通过时的修订方向 |
| --- | --- | --- |
| 导演表达 | 核心事件有当前产品依据；每镜有独立信息/感受贡献，高潮与收束可辨 | 找到重复镜与无因果炫技，调整事件路径或切点；不为求新破坏有效机制 |
| 输入与身份 | 所有图实际看过，属性权限明确，文字有权威；SKU、状态和实例数不混 | 定位冲突属性；保留构图有效部分并修正错误事实，未知不猜 |
| 动态与摄影 | 每个运动镜同时有独立的大幅相机路径和显著主体/料体变化；镜内有可辨认的真实远近/尺度发展，画幅内能看见结果；两端可回到相似尺度 | 先调路径/时序/相对速度，避免相机完全抵消；阅读窗只占局部，不能整镜缩动作 |
| 光影的导演贡献 | 光影使具体结构、材质、料体阶段或品牌得到新认识；主辅/错峰可读，有清楚结束状态；可有设计地稳定 | 去掉无信息的多次扫光，重排注意力；不以术语、灯数或更暗取胜 |
| 灯光的可执行性 | 来源/驱动、对象区域、方向范围、边界软硬、速度时序和终态相容；反射与投影不混、局部照明变化与全局曝光分开 | 核对灯/旗/物体/观察角各自是否可动，改路径/时序/切点而非冻结相机缩小主体；不要写互相矛盾的多个驱动 |
| 材质分化与阅读 | 金属亮暗塑形、玻璃厚度/透明度、磨砂散射、塑料固有色、凝胶与乳霜的响应各适用；文字窗口的尺度/角度/速度/反差同时成立 | 改光面范围、反射环境与观察路径；禁止材质替换、漂浮文字、厚乳霜通体透明和高光淹字 |
| 固定条件与分层 | 灯位、全部照明、背景照明、可见背景按用户实际语义锁定；改变的层不污染应稳定层 | 逐段查溢光、投影、反射/透射的变化，不用全屏亮度呼吸或偷加控光器 |
| 物性与过程 | 起态、受力、进度、终态连贯；外部意象与真实作用分开，物量不重复或凭空补充 | 保留必要中间过程，调整摄影以回避未知机构，不扩大功效 |
| 剪辑与接口 | 每个切点有关系和内容推进；产品/料体/相机/光影分别续接所需相位；展示时刻切换不被写成自动复原 | 明确事件续接/视觉联想/时间切换，再只匹配所需条件；光影跨段不暗中重启，不能只改表不改正文 |
| 时间与落版 | 连续0—30秒，转场/停留均已计入；末尾构图、姿态和品牌至少共同稳定1秒 | 调整前段节奏/落版入场路径及结束时刻，不能把变焦/淡出算停留 |
| 交付可用 | 用户模板与锁定内容保留；每单元完整可复制；上传编号、时长、局部时间、字符限额都有依据 | 补齐受影响单元，实际计数并留余量，不拿内部大纲代替正文 |

真正冲突举例：用户同时要求真实连续一镜、已不可逆混合完成、同一瓶在片尾恢复原始分层。不能凭“高级转场”消解。先说明冲突落在哪个物理/剪辑条件，再问允许改变的具体条件；其余设计继续保留。

试写合格只证明代理能按Skill写出经语义审查的文本，不能证明视频模型会保住文字、物性、时间或相机轨迹。实际视频、人工审阅、生产验收各需各自证据。
