# A-roll 媒体读取与影调参考帧

## 依赖与调用

需要 Python 3.10+ 标准库，以及 PATH 中的 `ffmpeg`、`ffprobe`。不需要 Python 图像包、母版 Skill 或 3D 软件。缺少工具时说明缺项，优先使用已有等效工具；不自动下载或安装依赖。

以下命令从 Skill 包目录执行，替换占位路径；输出放在实际项目或临时任务目录，不要放进 Skill 包。

```bash
python scripts/aroll_reference.py inspect --video "/project/aroll.mp4" --out "/project/broll-inspect"
python scripts/aroll_reference.py extract --video "/project/aroll.mp4" --at 2.0 --output "/project/broll/look-reference.png"
```

`inspect` 读取真实媒体信息并按全片时长均匀抽取 12 张预览，生成 `overview.jpg` 和 `inspection.json`；可用 `--samples` 调整到 2–48 张。样本序号与定位时间见 JSON，联系表从左到右、从上到下排列。采样数量只是查看工具的设置，与最终镜数无关。

`extract` 导出一张 PNG 和同名 `.json`。输出文件必须不存在；工具不覆盖用户已有产物。`--at` 是以秒为单位的原片定位请求，解码器选择对应可解码帧；可变帧率素材不把该数值伪称精确帧 PTS。

输出记录包含源文件 SHA-256、媒体元数据、定位时间及输出 SHA-256。PNG 保留原片解码后的色彩关系，不额外调色或增强；编码色彩转换不等于逐字节复制视频像素。旋转元数据按 FFmpeg 默认显示方向应用，非方形像素转换到正确显示比例，实际输出尺寸在 JSON 中记录。

## 判断与失败边界

- 必须打开联系表和所选原尺寸 PNG，结合原片连续运动挑选参考帧；脚本不会自动选出“最好的一张”。
- 联系表只能帮助定位场景和光色变化，不能证明已完整播放、听过音轨或核实运动曲线。可用播放能力缺失时如实保留动态分析限制，不把更密集抽帧当作播放验收。
- 均匀采样可能遗漏短镜头或抽中转场，按需在局部补抽，不靠场景变化检测的数量决定镜数。
- 视频色彩标签为空时记录为未知，不冒称已验证某个色彩空间。常见 SDR 可直接抽帧后与实际观看对照。
- 对已标记的 PQ/HLG 或 Dolby Vision HDR 输入，此小工具会停止，避免导出未经确定色调映射的错误影调图。改用现有可信色彩管理流程制作观看版并核对；不可默默套一个通用调色滤镜后称为原片影调。其他异常色彩、比例或旋转以实际检查为准。
- 不接受负数、非有限时间、越过视频末尾的定位或没有视频轨的文件。输入必须是本地文件；网络获取与生成不属于该脚本。
- 输出失败时保留诊断，不宣称已交付有效影调参考。重新选择一个新的输出文件名或空目录运行。

## 维护验证

```bash
python scripts/test_aroll_reference.py
```

测试自行合成短视频，检查时间边界、源文件不变、真实解码像素、中文含空格路径、样本／参考输出与来源哈希、重复输出拒绝和 HDR 检测。没有 FFmpeg 时集成测试明确失败，不用跳过来冒充实际抽帧通过。测试不评估功效创意、真实视频生成、摄影质量或剪辑效果。

包的媒体集成测试需要保留已安装 FFmpeg 所在的 PATH。若外部隔离器仅保留 Python 与系统目录，应把结构隔离检查与带媒体依赖的复制包实测分开运行，并分别记录结果；不要放宽隔离器或把真实抽帧测试改成无依赖假测试。本仓库的独立包测试发现器会自动在单独复制的包内运行本测试文件。
