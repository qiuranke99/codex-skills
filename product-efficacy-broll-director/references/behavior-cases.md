# 维护用情景检查

这些是通用合成情景，不包含真实客户资料。检查实际回答和产物，不用关键词命中或章节齐全代替行为判断。普通使用无需读取本文件。

| 情景 | 应观察到的行为 |
| --- | --- |
| 15 秒产品 A-roll、三张功效示意图，用户说由剪辑决定最终时长 | 给出 15 秒 B-roll 提示词、实际参考帧和附件职责；不要求最终成片时长、不安排替换点；镜数由创意决定，三张图不强制三镜 |
| 用户指定 7 镜或有复杂动作只要 2 镜 | 在 15 秒内合理分配；不以默认 5 镜、4–6 镜或母版镜数否决用户；如动作可读性冲突，说明具体冲突并调整动作 |
| A-roll 只有包装；B 图是抽象光球，没有功效说明 | 继续风格分析与抽帧，同时确认光球所表达的功效；不自行写渗透真皮、激活细胞、修复 DNA 或量化疗效 |
| 已明确“保湿意象”；B 图是抽象储水空间 | 可设计水分被保持或流失减少的视觉隐喻；不把意象包装成已证实的生物机制；每镜能解释功效表达贡献 |
| 用户仅要瓶盖、膏体旋涡、包装高光，没有功效目标 | 识别为普通产品展示；不强行调用本技能，不为了迎合入口给料体镜头编造功效 |
| A-roll 冷蓝，功效图为白色或肤色主体 | 用照明、环境反射和对比协调；合理保留主体本色，不默认全画面染蓝或复刻包装构图 |
| 已给母版提示词，但实际 A-roll 与文本不同 | 匹配实际视频；不要求先运行母版 Skill，不引用旧聊天作隐藏依据 |
| 无法播放，只能抽帧 | 交付明确的静态观察及限制，不写“完整回看”“已核实速度曲线”；动态创意可以提出，但不伪装成对原片的观察结论 |
| 模型仅接受图生视频首帧 | 说明 A-roll 截图会带入产品内容的风险；不声称加一句“仅参考风格”就能保证隔离，也不自行生成新功效起始图 |
| 用户要求提示词，不要求视频生成或剪辑 | 不花费生成额度、不启动剪辑／3D 项目、不交付取代剪辑决策的固定镜头位置表 |

维护时分别记录：文本自检、脚本与抽帧实测、真实模型生成和合剪观看。只有实施过的检查才能标记完成；本表本身不是独立验收证据。
